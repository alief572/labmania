## 1. Ringkasan Kebutuhan

Penjualan Program berstatus **Final** — **Public maupun B2B** — dibuatkan **Quotation** `[QDA-1]`.
Quotation adalah **persiapan invoice** `[INV-1]`. Penjualan **Public** dapat dibuatkan quotation
**berkali-kali** `[QDA-4]`; penjualan **B2B** **satu quotation** `[B2B-5]` (selain yang Batal `[USULAN]`).
~~**Sales Order tidak ada**~~ `[B2B-3]` — **to be:** Sales Order kembali ada. Setiap quotation **Deal** otomatis membentuk **satu Sales Order**, dan invoice dibuat dari Sales Order yang sudah ditandai siap dibuatkan invoice (`docs-to-be/fr-nfr-sales-order.md`, `input/Master - Buat Program/2026-11-07-sales-order/`).

Setiap quotation ditujukan ke salah satu `[QDA-2]`:

| | **Company** | **Personal** |
|---|---|---|
| Kepada | Company dari Master Company + u.p. | Nama yang dituju, **diisi di form** (peserta belum ada saat quotation dibuat) `[USULAN]` |
| Peserta | **Tidak dipilih** — form berisi **Kuota peserta** `[TB-2]`. Peserta diisi calon peserta sendiri lewat **link Konfirmasi Kehadiran** `[TB-4]`, **hanya lewat link** (tidak ada tambah manual oleh Sales) `input/Master - Buat Program/2026-11-09-peserta-hanya-lewat-link/`; tidak diambil dari Master Peserta `[TB-3]` | sama |
| Penjualan B2B | **Wajib** Company, terkunci ke Company Penjualan Program `[B2B-1]` + `[USULAN]` (terkunci) | Tidak tersedia `[B2B-1]` |

Beda **Public** dan **B2B** di Quotation:

| | **Public** | **B2B** (in-house, satu company) |
|---|---|---|
| Jumlah quotation | Berkali-kali `[QDA-4]` | **Satu** `[B2B-5]` |
| Tujuan | Company atau Personal | Company penjualan `[B2B-1]` |
| Kuota peserta | Minimal 1 `[TB-2]` | **Minimal 10** `[B2B-2]` |
| Skema harga | Per peserta | **Per peserta** atau **All-in 1 company** `[B2B-1]` |
| Diskon | Rupiah per peserta | Per peserta: Rupiah per peserta; All-in: Rupiah **total** `[BAD-1]` |
| Konfirmasi Kehadiran / Confirmation Letter | Link dengan isian template + pernyataan; Confirmation Letter dari isian `[TB-4]`, `[TB-5]` | **Sama dengan Public**: link dengan isian template + pernyataan, dan **Confirmation Letter** dari isian `input/Master - Buat Program/2026-11-09-b2b-tetap-confirmation-letter/` (Q-TB-03 terjawab; menggantikan as is `[B2B-4]`, `[BAD-3]`) |
| Invoice (`docs/fr-nfr-invoice.md`) | Satu invoice per quotation Deal | **Mengikuti skema**: all-in ke company = 1 invoice; per peserta = 1 invoice per peserta Deal (`input/Invoice & Pengajuan/2026-10-30-invoice-b2b-ikut-skema/`, menggantikan `[BAD-2]`) |

```
Penjualan Program Final (Public / B2B)
   └─► Quotation (Kuota peserta): Draft ──Kirim & Cetak──► Terkirim ──Deal──► Deal ──► Confirmation Letter (dari isian)
         │ simpan = link Konfirmasi Kehadiran dibuat      │                │         └─► Sales Order ──siap──► Invoice (docs-to-be/fr-nfr-sales-order.md)
         ▼                                                 │                │
      Calon peserta isi link ──► Data Peserta (hanya lewat link)          │
         (link terbuka: Draft/Terkirim, kuota belum penuh)                 │
                    └──────── Batalkan ───────────────────┴──► Batal (link ditutup)
```

## 6. Status Quotation

| Dari | Aksi | Ke | Efek |
|---|---|---|---|
| — | Simpan baru | Draft | Nomor dan **link Konfirmasi Kehadiran** dibuat; link terbuka |
| Draft | Edit | Draft | `[USULAN]` |
| Draft | Kirim dan Cetak Quotation | Terkirim | Terkunci; menunggu deal; link tetap terbuka sampai kuota penuh |
| Terkirim | Kirim dan Cetak Quotation | Terkirim | Cetak ulang |
| Terkirim | Deal (≥ 1 peserta dicentang dari Data Peserta) | Deal | Peserta dicentang = Deal, lainnya Batal; link ditutup; **Sales Order dibuat** (SO-FR-01) |
| Draft / Terkirim | Batalkan | Batal | Link ditutup |
| Draft / Terkirim | Isian link masuk | (tetap) | Peserta baru berstatus Menunggu; link tertutup otomatis saat kuota penuh atau setelah tanggal Berlaku sampai |
| Terkirim / Deal | Confirmation Letter (dari tab Data Peserta) | (tetap) | Lihat / unduh surat konfirmasi yang diunggah peserta, status tetap |
| Deal | Kirim dan Cetak Quotation | Deal | Cetak ulang |
| Batal | Lihat | Batal | — |

Status peserta dalam quotation: **Menunggu** (sejak mengisi link) → **Deal** / **Batal** (saat aksi Deal), atau
ikut **Batal** bila quotation dibatalkan. Status link: **Terbuka** (Draft/Terkirim, kuota belum penuh, belum melewati Berlaku sampai) / **Tertutup** (kuota penuh, Deal, Batal, masa berlaku berakhir) — turunan, tidak disimpan `[USULAN]`.
